# Disc Tools

A Linux GUI for optical-disc work: preservation dumping, verification against Redump data, and burning — built on the classic open-source disc toolchain.

## Credits

- **redumper** — by **superg** (preservation-grade dumping and verification)
- **xorriso / libburnia** — burning and ISO handling
- **cdrdao** — DAO reading/writing
- **GNU ddrescue** — damaged-disc recovery
- **growisofs (dvd+rw-tools)** — DVD/BD writing

This GUI orchestrates those tools; all credit for the underlying work belongs to their authors.
